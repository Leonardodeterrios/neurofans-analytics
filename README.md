# NeuroFans — аналитика источников (Threads → Telegram-бот)

Отслеживает, с какого аккаунта (по ссылке из био) человек пришёл в бота.
Метка в ссылке = **имя профиля**. Каждый заход:
- пишется в локальную базу `data/starts.db`,
- (опц.) уходит в Google-таблицу,
- (опц.) присылает тебе **уведомление в Telegram**.

> Секреты (токен бота, URL вебхука, admin id) хранятся в `.env` и **не попадают в git**.

## Файлы
| Файл | Назначение |
|---|---|
| `neurofans_bot.py` | Бот: ловит источник из deep-link, пишет в базу/таблицу, шлёт уведомления |
| `sheet_webhook.gs` | Google Apps Script: приёмник для таблицы (`starts` + `buildSummary()`) |
| `make_links.py` | Генератор ссылок с меткой по каждому профилю |
| `Dockerfile`, `docker-compose.yml` | Запуск одной командой |
| `.github/workflows/ci.yml` | Проверка синтаксиса при каждом пуше |

## Команды бота
- `/start <метка>` — вход (метку подставляет ссылка из био)
- `/myid` — узнать свой `chat_id` (нужен для `ADMIN_CHAT_ID`)
- `/stats` — сводка переходов по аккаунтам (только админ)

## Настройка
1. **Таблица (опц.):** Google-таблица → Расширения → Apps Script → вставь `sheet_webhook.gs`
   → разверни как веб-приложение (доступ: у кого есть ссылка) → URL положи в `SHEET_WEBHOOK_URL`.
2. **Секреты:** `cp .env.example .env`, заполни `BOT_TOKEN`, `BOT_USERNAME`.
   Для уведомлений — запусти бота, напиши ему `/myid`, полученный id впиши в `ADMIN_CHAT_ID`.
3. **Ссылки:** укажи профили в `make_links.py` → `python make_links.py` → ссылки в био.

## Запуск

### Локально
```bash
pip install -r requirements.txt
python neurofans_bot.py
```

### Docker (рекомендуется для сервера)
```bash
cp .env.example .env     # заполни
docker compose up -d --build
docker compose logs -f   # смотреть логи
```
База переходов сохраняется в `./data` между перезапусками.

## Аналитика
- Уведомления в Telegram — по каждому переходу (помечает «новый»/«повторный»).
- `/stats` в боте — переходы по каждому аккаунту (всего и уникальных).
- Лист `starts` в таблице + `buildSummary()` — то же самое в Google Sheets.

## Честность
Метка = имя профиля (канал привлечения), а не данные пользователя.
Онбординг бота честный: прямо обозначен как бот/обучение, с пометкой ИИ, без обещаний дохода.
