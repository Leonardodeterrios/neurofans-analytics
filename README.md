# NeuroFans — аналитика источников (Threads → Telegram-бот)

Отслеживает, с какого аккаунта (по ссылке из био) человек пришёл в бота.
Метка в ссылке = **имя профиля**. Каждый заход:
- пишется в локальную базу `data/starts.db`,
- (опц.) уходит в Google-таблицу,
- (опц.) шлёт тебе **уведомление в Telegram**.

Плюс: **веб-дашборд** с графиками и **алерты «тишина по источнику»**.

> Секреты (токены, URL, admin id) хранятся в `.env` и **не попадают в git**.

## Файлы
| Файл | Назначение |
|---|---|
| `neurofans_bot.py` | Бот: ловит источник, пишет в базу/таблицу, уведомления, /stats, /export, авто-сводка, алерты тишины |
| `dashboard.py` | Веб-дашборд (Flask + Chart.js): KPI, графики, таблица источников |
| `sheet_webhook.gs` | Google Apps Script: приёмник для таблицы |
| `make_links.py` | Генератор ссылок с меткой по каждому профилю |
| `Dockerfile`, `docker-compose.yml` | Бот + дашборд одной командой |
| `.github/workflows/ci.yml` | Проверка синтаксиса при каждом пуше |

## Команды и меню
После `/start` бот показывает **инлайн-меню с кнопками** (гайд / о продукте; у админа ещё статистика / CSV). Команды:
- `/start <метка>` — вход (метку подставляет ссылка из био)
- `/menu` — меню с кнопками
- `/myid` — узнать свой `chat_id`
- `/stats` — сводка переходов по аккаунтам (админ)
- `/export` — выгрузка всех переходов в CSV (админ)

## Уведомления и алерты
- **Каждый переход** → уведомление в ЛС («новый»/«повторный»).
- **Ежедневная авто-сводка**: задай `DAILY_SUMMARY_TIME` (напр. `09:00`) и `SUMMARY_TZ`.
- **Тишина по источнику**: если по аккаунту нет переходов дольше `SILENCE_HOURS` (деф. 24ч),
  бот присылает алерт «🔕 Тишина по источнику X» — повод проверить ссылку в био / статус аккаунта.
  Повторно по той же тишине не спамит; сбрасывается, когда по источнику снова пойдут переходы.

## Веб-дашборд
`dashboard.py` — страница с KPI (всего / уникальных / активных источников),
столбчатым графиком переходов по источникам, линией по дням и таблицей.
Читает ту же базу, что и бот. Автообновление каждые 30 сек.
- Локально: `python dashboard.py` → http://localhost:8080
- Пароль (опц.): задай `DASHBOARD_TOKEN`, тогда вход по `http://localhost:8080/?token=XXX`

## Настройка
1. **Таблица (опц.):** Apps Script → вставь `sheet_webhook.gs` → разверни как веб-приложение → URL в `SHEET_WEBHOOK_URL`.
2. **Секреты:** `cp .env.example .env`, заполни `BOT_TOKEN`, `BOT_USERNAME`.
   Для уведомлений/алертов — узнай `/myid` и впиши в `ADMIN_CHAT_ID`.
3. **Ссылки:** профили в `make_links.py` → `python make_links.py` → ссылки в био.

## Запуск

### Локально
```bash
pip install -r requirements.txt
python neurofans_bot.py      # бот
python dashboard.py          # дашборд (в отдельном терминале)
```

### Docker (бот + дашборд)
```bash
cp .env.example .env     # заполни
docker compose up -d --build
docker compose logs -f
```
Дашборд на http://localhost:8080, база переходов в `./data` (переживает перезапуски).

## Честность
Метка = имя профиля (канал привлечения), а не данные пользователя.
Онбординг бота честный: прямо обозначен как бот/обучение, с пометкой ИИ, без обещаний дохода.
