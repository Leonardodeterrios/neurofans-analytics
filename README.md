# NeuroFans — аналитика источников (Threads → Telegram-бот)

Отслеживает, с какого аккаунта (по ссылке из био) пришёл человек в бота.
Метка в ссылке = имя профиля. Все заходы пишутся в Google-таблицу.

> Секреты (токен бота, URL вебхука) хранятся в `.env` и **не попадают в git**.

## Файлы
- `neurofans_bot.py` — Telegram-бот: ловит источник из deep-link, пишет в таблицу.
- `sheet_webhook.gs` — Google Apps Script: приёмник, кладёт строки в лист `starts`.
- `make_links.py` — генератор ссылок с меткой по каждому профилю.

## Настройка
1. **Таблица**: Google-таблица → Расширения → Apps Script → вставь `sheet_webhook.gs`
   → Развернуть как веб-приложение (доступ: у кого есть ссылка) → скопируй URL.
2. **Секреты**: `cp .env.example .env` и заполни `BOT_TOKEN`, `BOT_USERNAME`, `SHEET_WEBHOOK_URL`.
3. **Бот**: `pip install -r requirements.txt` → `python neurofans_bot.py`.
4. **Ссылки**: укажи профили в `make_links.py` → `python make_links.py` → ссылки в био аккаунтов.

## Как читать аналитику
- Лист `starts` — все заходы: `время | источник(имя профиля) | user_id | username | имя`.
- Функция `buildSummary()` в Apps Script — сводка «переходов с каждого аккаунта».

## Честность
Метка = имя профиля (канал привлечения), а не данные пользователя.
Онбординг бота честный: прямо обозначен как бот/обучение, с пометкой ИИ, без обещаний дохода.
