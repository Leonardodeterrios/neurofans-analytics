## Как это работает
- Партнёры ставят в био ссылки вида `https://go.ai-creators.ru/t/<метка>` (Threads) или `/v/<метка>` (видео: Shorts/Reels/TikTok); `/go/<метка>` и `/go?source=` — без канала.
- Клик пишется в SQLite и редиректит в бота: `t.me/<BOT_USERNAME>?start=<метка>-<id клика в base36>` (старый вид `<метка>__<id>` тоже принимается).
- Воронка бота живёт в **PuzzleBot** (@AccessGrantedGuide_bot). Мы бота не поллим: токен нужен только для `sendMessage` (уведомления), иначе конфликт с PuzzleBot.
- PuzzleBot в команде /start делает «Отправить запрос» (GET):
  `/bot/start?p={{start_payload}}&uid={{USER_ID_TEXT}}&key=<INGEST_TOKEN>`.
- Команды: метки `leo01…leo50` → команда A («Команда Лёни», 🌊, #19d3c5), `kate01…kate50` → команда B («Команда Кати», 🌺, #ff4f8b). Префиксы/имена/цвета в `.env`.

## Правила подсчёта (не ломать без согласования)
- Удар (+1) = уникальный человек на партнёра за раунд. Человек = cookie `nf_vid`, иначе хэш IP+User-Agent.
- Один человек засчитывается максимум `MAX_PARTNERS_PER_VISITOR` (3) партнёрам за раунд; с IP — максимум `MAX_HITS_PER_IP` (100: за одним IP операторов сидит много людей).
- Боты/превью-краулеры/скрипты (`BOT_UA`) не пишутся, но получают **тот же** редирект, что и люди. Встроенные браузеры Instagram/Threads/TikTok/Facebook/YouTube — люди (покрыто тестами).
- IP: перед приложением стоит caddy и кладёт адрес соединения в `X-Real-IP`; приложение верит этому заголовку только от внутреннего (private) адреса, т.е. от caddy. `CF-Connecting-IP` — только при `TRUST_CF=1` (сейчас 0). Иначе IP можно подделать.
- Уникальность Telegram-аккаунта для апперкота — на всё время, не на раунд: апперкот = новый человек в боте, иначе одних и тех же людей можно «прогонять» каждый день.
- Апперкот (+`START_POWER`=3) = новый Telegram-аккаунт пришёл через **засчитанный** клик этого партнёра; один старт на клик. «Голые» t.me-ссылки и `direct` не считаются. Доходимость ≤ 100%.
- Сила = удары + 3 × апперкоты. Раунд — «от гонга до гонга» (`DAILY_SUMMARY_TIME`, по умолчанию 21:00 Asia/Bangkok); в гонг итоги уходят в Telegram всем `ADMIN_CHAT_ID` (через запятую).

## Принципиальные решения (договорённости с владельцем)
- Никакого клоакинга (разный ответ ботам площадок и людям), ротации доменов для обхода банов, «пачек» доменов чтобы площадки не связали ссылки. Один домен с HTTPS — ок (`go.ai-creators.ru`); партнёры могут ставить переадресацию со своих доменов на свою личную ссылку; каналы разделяются путями `/t` и `/v`.
- Продукт честный: ИИ-природа моделей раскрыта, без фейковых пруфов и обещаний дохода.
- Секреты (токены, пароли) только в `.env` на сервере — никогда в репозиторий и не просить их в чате.

## Файлы
- `app.py` — весь бэкенд (Flask): трекинг `/go /t /v`, `/bot/start`, `/api/stats`, `/api/feed`, `/arena`, дашборд `/` (HTML в константе `PAGE`), CSV `/export` и `/export/starts`, фоновый планировщик (итоги раунда, алерты «тишины»). Миграции БД — в `init_db()`.
- `arena.html` — Муай-тай арена (чистый SVG/JS, без библиотек): скелетная анимация бойцов (`rig()`, `POSE_DEF`, `MOVES`), эффекты, HUD. Режимы: LIVE (опрос `/api/feed` и `/api/stats`) и демо (`?demo`). Отладка в консоли: `window.__arena` (`pose`, `freeze`, `hold`, `strike`, `endNow`).
- `make_links.py` — генерирует `links.csv` (100 партнёров × ссылки Threads/видео) от `BASE_URL`.
- `Dockerfile`, `docker-compose.yml` — сервисы `app` (наружу не открыт, 8080) и `caddy` (80/443, `Caddyfile`): HTTPS Let's Encrypt для `DOMAIN` из `.env`, http://домен → https, любой другой http (голый IP, старые ссылки) проксируется как раньше. Данные в `./data`, сертификаты в `./caddy`.
- **Cloudflare не используем**: с 9 июня 2025 российские провайдеры режут сайты за Cloudflare (в ноябре 2026 всё ещё так), а часть аудитории в РФ. DNS домена — у регистратора, A-запись `go` → IP сервера.
- `deploy.sh` — первичная установка на чистый Ubuntu.
- `tests/test_core.py` — тесты ядра на заглушках (`tests/stubs`), запуск: `python3 tests/test_core.py`.

- Выкатка изменений: закоммитить и запушить в `main`, затем владелец запускает:
  `cd /opt/neurofans-analytics && git pull && docker compose up -d --build`
- Логи: `docker compose logs --tail=50 app`. Правка `.env`: `sed -i 's/^КЛЮЧ=.*/КЛЮЧ=значение/' .env` и `docker compose up -d --force-recreate`.
- Ссылки (`https://go.ai-creators.ru`): дашборд `/?token=<DASHBOARD_TOKEN>`, арена `/arena?token=<…>` (партнёрам — `PUBLIC_TOKEN`, без доступа к CSV/IP). Safari без `http://` пытается https и висит — давать полные ссылки.

## Как проверять правки
- Python: `python3 tests/test_core.py` (зависимости ставить не нужно).
- JS арены: вытащить `<script>` и `node --check`; внешний вид — Playwright + Chrome, открыть `arena.html?demo`, для живого режима мокать `/api/stats` и `/api/feed` через `page.route`.
- Шрифты Unbounded/Manrope и Chart.js грузятся из интернета — в песочнице их может не быть, это нормально.
